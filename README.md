# E-commerce-cybersecurity-consultancy
A cybersecurity consultancy proposal covering e-commerce security, cloud protection, threat modelling and system design. 
Threats Analysed

Ransomware, malware, identity-based attacks and denial-of-service attacks.

Proposed Security Controls

Backups, MFA, WAF, AWS Shield, disaster recovery and employee awareness training.

System Design

UML use-case and sequence diagrams for customer interactions, payments and inventory.

Threat Modelling

STRIDE and PASTA methodologies.

Skills Demonstrated

Cybersecurity consultancy, cloud security planning, threat identification, UML modelling and technical communication.
